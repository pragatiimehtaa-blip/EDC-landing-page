# VentureVerse 2026 — Ideas into Action | EDC JSS University

## Project Description
This project is a complete, responsive landing page for "VentureVerse 2026," an entrepreneurship-focused event organized by the Entrepreneurship Development Cell (EDC) of JSS University, Noida. The website presents event details, schedule, speaker profiles, registration form, live countdown, and FAQs.

Designed with a creative college student personality, the page supports both light and dark visual themes with an easy toggle. Built with only HTML, CSS, and beginner-friendly vanilla JavaScript.

## Technologies Used
- HTML5 for structure and accessibility
- CSS3 for styling, layouts, themes, and hover effects
- JavaScript for interactive features (theme toggle, mobile menu, countdown, form validation, FAQ accordion)

## Project Structure
- `index.html`: The main webpage structure with all required sections.
- `style.css`: Styling rules, responsive design, themes, and hover effects.
- `script.js`: JavaScript controlling interactivity and dynamic features.
- `README.md`: Project documentation and instructions.

## How to Run the Project
Simply open `index.html` in any modern web browser (like Chrome, Firefox, Edge). No server or build tools are required.

## Features Implemented
- Light/dark theme toggle with accessible button and color updates site-wide.
- Responsive navigation menu that transforms into a hamburger menu on small screens.
- Live countdown timer showing days, hours, minutes, and seconds until event start.
- Fully responsive layout using CSS Flexbox and Grid.
- Multiple subtle hover and focus effects on navigation, buttons, cards, speakers, schedule items, and footer icons.
- Event details: about, highlights, full schedule, speakers.
- Registration form with basic validation and success/error feedback without any page reload.
- FAQ section with accessible accordion toggling.
- Consistent design with a distinctive color palette.
- Speaker profiles are fictional placeholders designed to complete the UI.
  
## Important Notes
- **Speaker Profiles:** All speaker profiles are fictional placeholders intended to demonstrate design and layout.
- **Registration Form:** This frontend form validates input and displays messages but does not store or send any real data. Real registrations would require a backend or form service.
- **Countdown:** Uses the browser’s local time; times may vary if the client’s clock is incorrect.
